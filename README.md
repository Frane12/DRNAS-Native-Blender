# DRNAS Native Blender — Android ARM64

Experimental **native** Blender port for Android ARM64, independent of the private DRNAS EMU repository. No private emulator source code is copied here.

## Status

The first workflow compiles and verifies an Android AArch64 ELF smoke-test binary and checks out official Blender v4.5.4 source. **This is not a compiled Blender binary or APK.**

Next: cross-compile dependencies, configure and compile actual headless Blender, test the binary, then design Android GUI and APK packaging.

Blender remains licensed under its upstream terms; this is an unofficial experiment.
